# فایل‌های ثابت سایت

## عکس پروفایل

صفحه‌ی اصلی به دنبال فایل زیر می‌گردد:

```
assets/profile.jpg
```

اگر این فایل موجود نباشد، به‌جای عکس حروف «ا.ا» نمایش داده می‌شود و صفحه
هیچ خطایی نمی‌دهد. برای گذاشتن عکس، کافی است فایل را با همین نام در همین
پوشه قرار دهید — هیچ تغییری در کد لازم نیست.

توصیه‌ها:

- مربع (مثلاً ۶۰۰×۶۰۰ پیکسل)
- زیر ۲۰۰ کیلوبایت
- صورت در مرکز کادر

## رزومه

`resume-amirali-arjmand-lari.pdf` — از سه جای سایت لینک دارد: دکمه‌ی Hero،
سرتیتر بخش رزومه، و کارت تماس. برای به‌روزرسانی، فایل را با همین نام
جایگزین کنید.
