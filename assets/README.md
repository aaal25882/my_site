# فایل‌های ثابت سایت

| فایل | کاربرد |
| --- | --- |
| `logo-mask.png` | نشانِ کوفی ستاره‌ای — در دایره‌ی لوگوی هدر و به‌عنوان تصویر پیش‌نمایش شبکه‌های اجتماعی (`og:image`) |
| `resume-amirali-arjmand-lari.pdf` | رزومه — از سه جا لینک دارد: دکمه‌ی «دانلود رزومه» در هدر، سرتیتر بخش رزومه، و منوی موبایل |

برای به‌روزرسانی هرکدام، فایل را با همین نام جایگزین کنید؛ تغییری در کد لازم نیست.

ویدیوی پس‌زمینه‌ی صفحه‌ی اصلی از یک آدرس بیرونی بارگذاری می‌شود و اینجا نیست
(به `index.html`، تگ `<video>` نگاه کنید).
